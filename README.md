# Computer Networks Practicals

This repository contains Cisco Packet Tracer (`.pkt`) lab configurations and network simulation files for Computer Networks practical assignments.

## 📁 Repository Structure

* `prac-1.pkt` - Practical 1 Configuration
* `prac-2.pkt` - Practical 2 Configuration
* `prac-3.pkt` - Practical 3 Configuration
* `prac-4.pkt` - Practical 4 Configuration
* `prac-5.pkt` - Practical 5 Configuration

## 🛠 Prerequisites

* **Cisco Packet Tracer** (Recommended version 8.0+) to open and run `.pkt` simulation files.

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mohammadkhizer/CN-practicals.git
   ```
2. Open any `.pkt` file with Cisco Packet Tracer to inspect or test the topology and configurations.
